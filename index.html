Problemas Matemáticos

Cuatro ejercicios interactivos de matemáticas

1. El reparto de los camellos

Introduce la cantidad de camellos originales. Se agregará uno temporalmente para realizar el reparto.

2. La venta de los melones

Introduce las cantidades de melones y las condiciones de venta de cada hermano. Después, compara la venta por separado con la venta conjunta.

3. Ecuación cuadrática

Resuelve la ecuación ax² + bx + c = 0 introduciendo sus coeficientes.

4. Aproximación de pi

Introduce la cantidad de términos para calcular una aproximación de pi mediante una suma matemática.
